## 1. Problem Description

Given two integers `numerator` and `denominator`, return the fraction as a string. If the fractional part repeats, enclose the repeating part in parentheses.

---

## 2. Examples

| numerator | denominator | Output |
|-----------|-------------|--------|
| 1 | 2 | "0.5" |
| 2 | 1 | "2" |
| 2 | 3 | "0.(6)" |
| 4 | 333 | "0.(012)" |
| 1 | 6 | "0.1(6)" |

*Explanation:* The decimal expansion is generated by long division; when a remainder repeats, the digits between the first occurrence and the second form the repeating cycle.

---

## 3. Key Insight

> Track remainders during long division. A repeating decimal cycle begins when a remainder recurs. Map each remainder to its position in the result string to insert parentheses.

---

## 4. Approach: Long Division + Hash Map — O(denominator) ✅

```text
FUNCTION fractionToDecimal(numerator, denominator):
    IF numerator = 0 THEN
        RETURN "0"
    SET result ← ""
    // Sign handling
    IF (numerator < 0) XOR (denominator < 0) THEN
        result ← result + "-"
    SET num ← ABS(numerator)
    SET den ← ABS(denominator)
    // Integral part
    SET result ← result + STRING(num DIV den)
    SET remainder ← num MOD den
    IF remainder = 0 THEN
        RETURN result
    result ← result + "."
    // Fractional part
    SET remainderMap ← {}
    WHILE remainder ≠ 0:
        IF remainder IN remainderMap THEN
            SET start ← remainderMap[remainder]
            SET result ← SUBSTRING(result, 0, start) + "(" + SUBSTRING(result, start) + ")"
            BREAK
        remainderMap[remainder] ← LENGTH(result)
        remainder ← remainder * 10
        SET digit ← remainder DIV den
        result ← result + STRING(digit)
        remainder ← remainder MOD den
    RETURN result
```

## 5. Walkthrough

Take `numerator = 4`, `denominator = 333`:
1. Sign positive, `num = 4`, `den = 333`.
2. Integral part `4 DIV 333 = 0` → result `"0"`.
3. Remainder `4 MOD 333 = 4`; add decimal point → `"0."`.
4. Loop:
   - remainder `4` not seen → map `4 → 2` (position after "0.").
   - `remainder = 4 * 10 = 40`; digit `40 DIV 333 = 0`; result `"0.0"`; remainder `40 MOD 333 = 40`.
   - remainder `40` not seen → map `40 → 3`.
   - `remainder = 40 * 10 = 400`; digit `400 DIV 333 = 1`; result `"0.01"`; remainder `400 MOD 333 = 67`.
   - continue similarly, eventually remainder `67` repeats after generating digits `012`.
5. When remainder repeats, insert parentheses around `012` → final result `"0.(012)"`.

---

## 6. Complexity Analysis

- **Time:** O(denominator) – each remainder is processed at most once before a repeat occurs.
- **Space:** O(denominator) – storage for the remainder map.
