## 1. Problem Description

Given two strings `s` and `t`, where `t` is generated by shuffling `s` and adding one extra character, find that extra character.

**Constraints:**
- `0 <= s.length <= 1000`
- `t.length == s.length + 1`
- `s` and `t` consist of lowercase English letters.

---

## 2. Examples

```
Example 1:
  Input:  s = "abcd", t = "abcde"
  Output: "e"

Example 2:
  Input:  s = "", t = "y"
  Output: "y"
```

---

## 3. Key Insight

> XOR all characters in both strings. Every character that appears in `s` also appears in `t` — they cancel out via `x ^ x = 0`. The only remaining value is the extra character.

---

## 4. Approach: XOR — O(n) ✅

```
FUNCTION findTheDifference(s, t):
    result = 0
    FOR c IN s + t: result ^= ord(c)
    RETURN chr(result)
```

---

## 5. Walkthrough

```
s = "abcd", t = "abcde"

XOR: a ^ b ^ c ^ d ^ a ^ b ^ c ^ d ^ e
   = (a^a) ^ (b^b) ^ (c^c) ^ (d^d) ^ e
   = 0 ^ 0 ^ 0 ^ 0 ^ e
   = e ✅
```

## 7. Follow-Up Questions

### 7.1 Can you use sum instead of XOR?

Yes — `sum(ord(c) for c in t) - sum(ord(c) for c in s)` gives the extra character's ASCII value. But this risks integer overflow in some languages.

### 7.2 Can you use a frequency counter?

Yes — count characters in `s`, decrement for `t`, the one with count -1 is the answer. Uses O(26) = O(1) space.

### 7.3 How does this relate to "Single Number" (LC 136)?

Identical technique — XOR cancels paired elements, leaving the unique one.

---

## 8. Key Takeaway

> **XOR cancellation** is the O(n)/O(1) trick for finding the single unique element when all others are paired. It works for characters, integers, or any XOR-able type.
