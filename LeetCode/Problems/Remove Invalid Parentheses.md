# 301. Remove Invalid Parentheses

**Difficulty:** 🔴 Hard
**LeetCode:** [https://leetcode.com/problems/remove-invalid-parentheses](https://leetcode.com/problems/remove-invalid-parentheses)
**Companies:** Amazon, Bloomberg, Deliveroo, Google, Meta, Microsoft, Millennium, Oracle, Rubrik, Tiktok

---

## Problem Description
Given a string `s` containing only letters and parentheses `'('` and `')'`, remove the minimum number of invalid parentheses to make the string valid. Return all possible results in any order. A string is valid if parentheses are correctly matched.

## Examples
**Example 1:**
```
Input: s = "()())()"
Output: ["()()()","(())()"]
```
**Explanation:** Two removals are required; both results are valid.

**Example 2:**
```
Input: s = "(a)())()"
Output: ["(a)()()","(a())()"]
```
**Explanation:** Same as above with letters preserved.

## Approach
Perform a breadth‑first search over strings generated by removing one parenthesis at each level. The first level that yields any valid strings corresponds to the minimum number of removals. Use a set to avoid duplicate strings.

```text
FUNCTION removeInvalidParentheses(s):
    SET queue ← {s}
    SET visited ← {s}
    WHILE queue NOT EMPTY:
        SET levelValid ← []
        FOR candidate IN queue:
            IF isValid(candidate):
                APPEND candidate TO levelValid
        IF levelValid NOT EMPTY:
            RETURN levelValid   // minimum removals reached
        SET nextQueue ← {}
        FOR candidate IN queue:
            FOR i ← 0 TO LENGTH(candidate) - 1:
                IF candidate[i] IN ['(', ')']:
                    SET newStr ← candidate[0:i] + candidate[i+1:]
                    IF newStr NOT IN visited:
                        ADD newStr TO visited
                        ADD newStr TO nextQueue
        SET queue ← nextQueue
    RETURN [""]
```

## Walkthrough
| Step | Queue size | Example candidate | Valid? | Next level generated |
|------|------------|-------------------|--------|----------------------|
| 1 | 1 | "()())()" | false | remove each parenthesis → {"())()","()()()","()()))","()())"}
| 2 | 4 | "()()()" | true → added to result, stop | — |
|   |   | "(())()" | true → added to result, stop | — |

## Complexity Analysis
- **Time:** In the worst case O(2^n) where n is the length of `s`, because each character may be removed.
- **Space:** O(2^n) for storing visited strings and the queue.

## Follow-Up Questions
1. How would you implement a depth‑first search with pruning to achieve the same result?
2. Can you modify the algorithm to return results in lexicographic order?
3. How would you handle strings that contain other types of brackets (`[]`, `{}`)?

## Key Takeaway
BFS over removal levels guarantees the minimal number of deletions, and using a visited set prevents redundant work.
