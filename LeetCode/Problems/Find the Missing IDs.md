## 1. Problem Description

Given a `Customers` table with IDs, find all IDs from 1 to the maximum ID that are **not** in the table. (SQL problem)

---

## 2. Examples

| Customers Table (customer_id) | Missing IDs |
|-------------------------------|-------------|
| 1, 2, 4, 5                    | 3           |
| 2, 3, 7, 8                    | 1, 4, 5, 6 |

*Explanation*: For the first row, IDs 1‑5 exist except 3, so the result is `3`. For the second row, the maximum ID is `8`; IDs `1,4,5,6` are absent.

---

## 3. Approach: SQL Recursive CTE ✅

```sql
WITH RECURSIVE seq AS (
    SELECT 1 AS id
    UNION ALL
    SELECT id + 1 FROM seq WHERE id < (SELECT MAX(customer_id) FROM Customers)
)
SELECT id AS ids
FROM seq
WHERE id NOT IN (SELECT customer_id FROM Customers)
ORDER BY id;
```

Alternative: Generate numbers using a numbers table or `GENERATE_SERIES` if available.

---

## 4. Walkthrough

1. **Generate full range**: The recursive CTE `seq` creates a sequence from `1` up to the maximum `customer_id`.
2. **Identify gaps**: The outer query selects IDs from `seq` that are not present in `Customers` using `NOT IN`.
3. **Order result**: The final `ORDER BY id` returns missing IDs in ascending order.

For the first example (`Customers` = {1,2,4,5}):
- `seq` produces `{1,2,3,4,5}`.
- `NOT IN` filters out `{1,2,4,5}`, leaving `{3}`.

---

## 5. Complexity Analysis

- **Time**: O(N) where N is the maximum ID, due to generating the sequence and scanning the table.
- **Space**: O(N) for the temporary sequence generated by the CTE.

## 7. Key Takeaway

> Use a **recursive CTE to generate the full ID range**, then anti‑join with the existing table to find gaps.
