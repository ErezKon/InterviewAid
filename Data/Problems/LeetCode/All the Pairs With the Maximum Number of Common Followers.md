# 1951. All the Pairs With the Maximum Number of Common Followers

**Difficulty:** 🟡 Medium
**LeetCode:** [https://leetcode.com/problems/all-the-pairs-with-the-maximum-number-of-common-followers](https://leetcode.com/problems/all-the-pairs-with-the-maximum-number-of-common-followers)
**Companies:** Lime

---

## 1. Problem Description

**SQL Problem.** Given a `Relations` table (`user_id`, `follower_id`), find all pairs of users who share the **maximum** number of common followers.

---

## 2. Examples

**Example 1**
```
Relations:
| user_id | follower_id |
|---------|-------------|
| 1       | 10          |
| 1       | 11          |
| 2       | 10          |
| 2       | 12          |
| 3       | 10          |
| 3       | 11          |
| 3       | 12          |
```
**Output**
```
| user1_id | user2_id |
|----------|----------|
| 1        | 3        |
| 2        | 3        |
```
*Explanation*: Users 1 & 3 share followers 10 & 11 (2 common). Users 2 & 3 share followers 10 & 12 (2 common). No other pair has more than 2 common followers.

**Example 2**
```
Relations:
| user_id | follower_id |
|---------|-------------|
| 5       | 20          |
| 5       | 21          |
| 6       | 22          |
```
**Output**
```
[]
```
*Explanation*: No pair of users shares any follower, so the result is empty.

---

## 3. Approach: Self-Join + Aggregation ✅

```sql
WITH common AS (
    SELECT r1.user_id AS user1_id, r2.user_id AS user2_id,
           COUNT(*) AS common_count
    FROM Relations r1
    JOIN Relations r2 ON r1.follower_id = r2.follower_id AND r1.user_id < r2.user_id
    GROUP BY r1.user_id, r2.user_id
)
SELECT user1_id, user2_id
FROM common
WHERE common_count = (SELECT MAX(common_count) FROM common);
```

---

## 4. Walkthrough

| Step | Action | Result |
|------|--------|--------|
| 1 | Self‑join `Relations` on `follower_id` with `r1.user_id < r2.user_id` | Generates every pair of users that share a follower |
| 2 | `COUNT(*)` groups by the user pair to compute how many followers they share | Each row now has `common_count` |
| 3 | Subquery `SELECT MAX(common_count)` finds the highest shared count | Determines the target count |
| 4 | Outer query filters pairs whose `common_count` equals the maximum | Returns the desired pairs |

---

## 5. Complexity Analysis

- **Time Complexity**: `O(N²)` in the worst case, where `N` is the number of rows in `Relations`, due to the self‑join.
- **Space Complexity**: `O(P)` for `P` distinct user pairs generated by the join.
