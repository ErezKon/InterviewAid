# 668. Kth Smallest Number in Multiplication Table

**Difficulty:** 🔴 Hard
**LeetCode:** [https://leetcode.com/problems/kth-smallest-number-in-multiplication-table](https://leetcode.com/problems/kth-smallest-number-in-multiplication-table)
**Companies:** De Shaw, Google, Medianet, Meta, Uber

---

## 1. Problem Description

Nearly everyone has used the Multiplication Table. The multiplication table of size `m x n` is an integer matrix `mat` where `mat[i][j] == i * j` (**1-indexed**).

Given three integers `m`, `n`, and `k`, return *the *`k^th`* smallest element in the *`m x n`* multiplication table*.

**Constraints:**
- `1 <= m, n <= 3 * 10^4`
- `1 <= k <= m * n`

---

## 2. Approach: Binary Search on Value — O(m log(mn)) ✅

Binary search on the answer. For a candidate `mid`, count values ≤ mid: row `i` contributes `min(mid/i, n)` values.

```text
FUNCTION findKthNumber(m, n, k):
    lo ← 1
    hi ← m * n
    WHILE lo < hi:
        mid ← (lo + hi) / 2
        count ← 0
        FOR i ← 1 TO m:
            count ← count + MIN(mid / i, n)
        IF count >= k:
            hi ← mid
        ELSE:
            lo ← mid + 1
    RETURN lo
```

| Time | Space |
|------|-------|
| O(m · log(m·n)) | O(1) |

## Examples

**Example 1:**
```
Input: m = 3, n = 3, k = 5
Output: 3
Explanation: The 5^th smallest number is 3.
```

**Example 2:**
```
Input: m = 2, n = 3, k = 6
Output: 6
Explanation: The 6^th smallest number is 6.
```

## Walkthrough

| Step | lo | hi | mid | count ≤ mid | Action |
|------|----|----|-----|------------|--------|
| 1 | 1 | 6 | 3 | 5 | count ≥ k → hi = 3 |
| 2 | 1 | 3 | 2 | 3 | count < k → lo = 3 |
| 3 | 3 | 3 | - | - | lo == hi → answer 3 |

---

## Complexity Analysis

- **Time:** O(m · log(m·n)) – binary search over the value range with O(m) counting per iteration.
- **Space:** O(1) – only constant extra variables.
